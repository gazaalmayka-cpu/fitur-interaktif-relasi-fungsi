Strategi umum membuktikan identitas (seperti di soal PDF)

  1. Ubah semua ke sin dan cos (hindari sec, csc, tan dulu jika membingungkan).
  2. Kerjakan satu sisi (biasanya yang lebih rumit) sampai sama dengan sisi lain.
  3. Gunakan identitas Pythagoras: sin² + cos² = 1, 1 + tan² = sec², dll.
  4. Faktorkan, kalikan sekawan, atau pecah pecahan.
  5. Jika ada sudut 2θ / 3θ / θ/2 → pakai rumus sudut ganda / setengah / tiga kali.
  6. Untuk A+B+C=π → ganti C = π−(A+B) lalu sederhanakan.
  7. Setelah aljabar selesai, uji numerik dengan beberapa nilai sudut untuk memastikan.
