# TrigonoLab S1

Laboratorium Trigonometri interaktif untuk mahasiswa S1.

**Buka aplikasi:** buka file `index.html` di folder ini, atau lewat GitHub Pages jika sudah diaktifkan:

https://gazaalmayka-cpu.github.io/fitur-interaktif-relasi-fungsi/trigono-lab-s1/

## Fitur
- Materi lengkap trigonometri S1
- Konversi derajat ↔ radian
- Nilai eksak sin/cos/tan
- Operasi sudut bebas (A±B, 2A, 3A) untuk 6 fungsi trig
- Sudut ganda & setengah (6 fungsi)
- Polar ↔ Kartesius
- Pembuktian identitas terperinci (bisa diubah sendiri)
- Uji numerik identitas
- Latihan & daftar rumus
